================================================================================
CRITICAL FEATURE: 2-PERSON AWAY ALERT
================================================================================

Implementation Details:

When patient is exactly 2 positions away from consultation:

1. Doctor calls next patient (position changes)
2. System checks: if nextQueue.position === currentPatient.position - 1
3. If true: 2-person-away condition detected
4. WebSocket event emitted:
   {
     event: "queue:two-people-away",
     data: {
       appointmentId,
       tokenNumber,
       currentToken,
       timestamp
     }
   }
5. Frontend receives alert → displays notification to patient
6. Patient knows they're next after current patient finishes

Verification Method:
- Position 5 (5 people ahead)
- Token 1,2,3,4 called → Position becomes 2
- System detects: nextQueue (token 1) at position 1, current patient at position 2
- Alert emitted! Patient notified they're 2 away
